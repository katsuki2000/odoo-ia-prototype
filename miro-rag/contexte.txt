# Log of Changes and Modifications

## 1. Added Defensive Tool Fallback & Effective Limit Handling (`tools/odoo_tools.py`)
- Updated `get_sale_details` tool:
  - Added defensive fallback to query all active sales orders (`state != cancel`) if a specific status query (e.g. `confirmé`) returns 0 records.
  - Set `effective_limit = 0` when `limite <= 1` to prevent single-record truncation and ensure all active sales orders (`S00002` + `S00010`) are fetched for Madagascar Tech (`5 300 000 Ar`).
- Created `_normalize_client_name()` helper to replace French accented characters (`é`, `è`, `ê`, `à`, `ç`, etc.) with SQL wildcard `_` in `ilike` queries.
- Applied `_normalize_client_name()` across all partner/client search domains (`get_total_sales`, `get_total_invoices`, `search_partner`, `get_recent_tickets`, `get_average_sales`, `get_sale_details`).

## 2. Added Global Data Sourcing Requirement to System Prompt (`rag/graph.py`)
- Updated `system_prompt` in `rag/graph.py` to enforce global data sourcing instruction across all agent responses:
  "Indique toujours la source exacte des données à la fin de ta réponse (ex: [Source: Odoo ERP - Module ...])."

## 3. Refactored `tools/odoo_tools.py` to Self-Describing Schemas & English Function Signatures
- Renamed all `@tool` definitions from French to English per project rule (`code in english`):
  - `get_total_sales` (formerly `obtenir_total_ventes`)
  - `get_product_stock` (formerly `obtenir_stock_produit`)
  - `get_order_status` (formerly `obtenir_statut_commande`)
  - `get_total_invoices` (formerly `obtenir_total_factures`)
  - `search_partner` (formerly `rechercher_client`)
  - `get_recent_tickets` (formerly `obtenir_tickets_recents`)
  - `list_out_of_stock_products` (formerly `lister_produits_en_rupture`)
  - `get_period_revenue` (formerly `obtenir_ca_periode`)
  - `get_average_sales` (formerly `obtenir_moyenne_ventes`)
  - `get_sale_details` (formerly `obtenir_details_ventes`)
- Updated `get_recent_tickets` default `limite` from 5 to 0 to display all matching records (resolving ERP-04 to display all 11 resolved tickets).
- Added explicit source tracking footer `[Source: Odoo ERP - Module Projet (project.task)]` to ticket output.
- Maintained backward-compatibility aliases (`obtenir_total_ventes = get_total_sales`, etc.).

## 4. Generalised `rag/graph.py` System Prompt
- Simplified system prompt from ad-hoc rule lists to a clean, concise, general-purpose instruction:
  "Tu es MIRO Assistant, l'assistant IA interne spécialisé dans les données ERP Odoo. Utilise les outils disponibles pour interroger la base de données en temps réel et réponds avec les informations exactes retournées."
- Eliminated prompt overfitting to ensure high generalization performance on real-world user queries.

## 5. Updated `tools/odoo_connector.py`
- Updated `search_read` signature to accept `order: str = None` and `**extra_kwargs` so sorting clauses are safely passed to XML-RPC.

## 6. Updated `tools/ingest_fake_data.py`
- Added explicit `action_cancel` execution for sales orders marked with `statut == 'annulé'` in `sales.json` (such as `SO-MIRO-0018`).
- Resolved client `partner_id` mapping for support tickets (`project.task`) during creation.

## 7. Updated `tools/full_setup.py`
- Created single consolidated setup script for Odoo single-company environment (`Company Alpha`).
- Added creation of sales journal (`account.journal` type `sale`, code `SJA`) for `Company Alpha`.
- Added creation of `Miro Manager` (`manager@miro.com`) user with multi-company and manager access rights.
- Added creation of Income Account `400000` (`Ventes de marchandises / Services`) and assigned it to the default product category (`product.category`) to enable XML-RPC invoicing without account error faults.
- Added re-writing of `date_order` after `action_confirm` to preserve historical order dates.
- Ensured all header docstrings and internal section comments are in English with no emojis to comply with project rules.

## 8. Updated `tools/date_utils.py`
- Added handling for `"à ce jour"` / `"ce jour"` in `parse_period` to return `None` (query all time without date lower bound).
- Fixed variable scope for `today = date.today()`.
